# 📊 Universal Data Analytics Dashboard

A premium, high-contrast data exploration tool built with **Streamlit**, **Pandas**, and **Seaborn**. This dashboard allows users to upload any CSV, perform automated data cleaning, generate professional visualizations, and build custom pivot tables on the fly.

![Dashboard Preview](https://img.shields.io/badge/UI-Professional-blue)
![Python Version](https://img.shields.io/badge/Python-3.8%2B-green)
![Streamlit](https://img.shields.io/badge/Streamlit-1.30%2B-FF4B4B)

## ✨ Key Features

- **🌓 Dynamic Theme Engine**: Toggle between a deep-navy Dark Mode and a crisp Slate Light Mode.
- **🧹 Auto-Cleaning**: One-click removal of duplicates and intelligent missing value imputation (Median for numbers, Mode for categories).
- **📈 Advanced Visuals**: Interactive Histogram, Bar, Pie, Line, and Scatter plots that automatically adapt to your chosen theme.
- **🧮 Smart Pivot Tables**: Dynamic aggregation (Sum, Mean, Count) for deep-dive multi-dimensional analysis.
- **🎨 Premium UI**: Custom CSS-injected "Glassmorphism" metrics and a sleek HTML header banner.
